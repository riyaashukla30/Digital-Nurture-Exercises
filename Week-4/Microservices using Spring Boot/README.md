# Spring Boot REST API - Country Service

## 📌 Overview
This project is a simple Spring Boot REST API that provides country details.

## 🚀 Features
- Get all countries
- Get country by code
- Exception handling for invalid country

## 🔗 API Endpoints
- `GET /countries` → Get all countries  
- `GET /countries/{code}` → Get country by code  

## 🛠️ Tech Stack
- Java  
- Spring Boot  
- Maven  

## ▶️ Run the Project
```bash
mvn spring-boot:run
